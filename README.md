# prompt-master · 提示词 skill

把脑子里模糊的画面，变成模型能看懂、能稳定复现的提示词；把手里粗糙的提示词，修成没有漏洞、没有废话、没有冲突的好提示词。

**中英双语**：同一个提示词，按需出中文版、英文版，或中英各一份。图片、视频类提示词默认英文更稳；纯文字类按用户说的语言出。

## 这是什么

一个给 AI 助手用的 skill，三种用法：

- **生成**：用户说一个粗糙想法（“想要一张黄色小怪物坐在跑步机上的图”），输出打磨好的结构化提示词，直接粘贴到模型里就能用。
- **优化**：用户贴一段粗糙提示词，先逐项诊断（缺了什么、哪里矛盾、哪些词是废话、有没有翻译腔），再给出修好的版本，并写清每处改了什么、为什么改。
- **识图反推**：用户贴一张图，按图片九维逐项分析，反推出可直接提交的提示词（英文版 + 中文版），附还原度要点、可调参数和否定提示词；视频用首帧 / 关键帧反推。

图片和视频两条线都覆盖，再扩到识图反推、文案/营销、电商、教育、代码/Agent、音频/音乐、3D/设计、日常办公 7 个新场景，适配 Seedance、Kling、Midjourney、Nano Banana / Gemini 图像、Veo、Sora、GPT 图像、Flux、Stable Diffusion、Runway、Luma、即梦等 12 个主流模型。只写提示词，不调用任何生成接口，不替用户生成图片或视频。

## 能干什么

- **图片提示词**：按九维写全——主体、风格、材质、光线、构图、镜头、色彩、氛围、画质词，中英对照。
- **视频提示词**：按七维写全——主体运动、镜头运动、时间节奏、转场、首尾帧、音频、一致性，中英对照。
- **识图反推**：贴一张图，按九维逐项分析，反推出可直接提交的提示词（英文版 + 中文版），附还原度要点、可调参数和否定提示词；视频用首帧 / 关键帧反推。只描述画面里看得见的东西，不编造看不见的细节；画面里的文字原样转录。
- **更多场景**：文案/营销、电商、教育、代码/Agent、音频/音乐、3D/设计、日常办公，各有结构和模板。
- **优化诊断**：9 项快速检查 + 8 类细查（缺失维度、矛盾描述、模糊词、否定词与废话、结构问题、对白与声音、参考图与角色、中英专项检查）。
- **负向提示词**：单独一节，含常见翻车词和分模型写法。
- **万能模板**：六个直接套用的模板——电影感短片、产品图、角色一致性、营销文案、Agent 任务指令、电商商品主图，全部中英对照。
- **模型指南**：12 个模型怎么写、忌讳什么、中文还是英文提示词更好，不确定的地方标明“以官方最新文档为准”，不编参数、不编版本号。
- **中英对照词表**：`references/bilingual-glossary.md`，画面、镜头、光线、风格、动作、情感、场景、音频、文案、代码常用词中英对照，附翻译避坑速查。
- **小工具**：`scripts/check_prompt.py`，检查一段提示词的长度、维度覆盖、模糊词、否定词、画面内文字语言、语言混用和翻译腔。

## 安装使用

```bash
npx skills add WanCai8908/prompt-master
```

装好后直接对助手说：

- “帮我写个提示词：一只橘猫从窗台跳上餐桌偷小鱼”——按生成工作流出结构化提示词，默认中英各一份。
- “优化一下这段提示词：……”——先诊断，再给优化版和改动说明。
- “这张图的提示词怎么写？”（贴一张图）——按工作流 C 识图反推，附还原度要点和可调参数。
- “这段提示词为什么出图总翻车？”——先讲问题，再给修好的版本。
- “用 Seedance / Kling / Midjourney 写”——按对应模型的写法来。
- “帮我写个卖保温杯的文案”——按营销文案模板出。
- “给编程助手写个任务指令”——按 Agent 任务指令模板出。

## 三条用法

**生成**：说清想法 → 助手问清关键项（图片还是视频、主体、风格、模型、比例、语言）→ 输出结构化提示词（中文、英文或中英各一份）+ 中文说明。

**优化**：贴上原提示词 → 助手按检查清单逐项诊断（含中英专项检查）→ 输出优化版 + 改动说明。没有问题的部分不动，优化不是重写。

**识图反推**：贴一张图 → 助手按九维逐项分析（看得见的写，推测的标明）→ 输出反推出的提示词（英文版 + 中文版）+ 还原度要点 + 可调参数 + 否定提示词。视频用首帧 / 关键帧反推。

## 铁律（摘要）

1. 不改用户的核心意图：主体、事件、结局，用户说了算。
2. 只写镜头能看到的；画面外的东西写成可见效果或声音。
3. 状态不用否定词：想去掉什么，写正面状态或删句。
4. 对白只能用用户原话，一个字都不能编。
5. 画面里的文字只用一种语言。
6. 不编造模型参数和版本号，不确定的写“以官方最新文档为准”。
7. 参数（时长、比例、分辨率）不进提示词正文，在生成设置里定。
8. 中英同步：模板、词表、例子中英对照；抽象词先拆成可见元素再翻，不直译成语和网络梗。

完整规则见 `SKILL.md`。
