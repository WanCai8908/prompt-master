# 识图反推检查清单（image-reverse-prompt）

反推不是“看图说话”，是把画面拆成模型能执行的词。顺序固定：先按九维逐项看图，再拼提示词，最后给还原度要点和可调参数。所有例子都有中英对照。

---

## 一、逐维检查清单：看什么、怎么写

每维先写“看什么”（眼睛盯着哪里），再写“怎么写”（落到提示词里的句式）。只写图里直接看得见的东西，看不见的一律不写。

### 1. 主体（Subject）

**看什么**：图里有几个主体；每个主体是谁 / 什么；长什么样（颜色、体型、标志性物件）；穿什么、拿什么；什么姿态、朝向哪里。

**怎么写**：数量写死（`one / two`，不要写 `some`）；外貌写可见特征，不要写性格标签；姿态写定格瞬间，不要写“正在享受”。

```text
英文：a yellow round chubby character with big blue eyes and tiny orange feet,
sitting on a pink treadmill, drinking from a green cup with a straw
中文：一个黄色圆滚滚的角色，大大的蓝眼睛，小小的橘色脚丫，
坐在粉色跑步机上，用吸管喝着绿色杯子里的饮料
```

### 2. 风格（Style）

**看什么**：画面整体长什么样——是照片、3D 动画、动漫、插画还是水彩；线条是干净还是粗糙；边缘是锐利还是柔和；有没有明显的渲染感或手绘感。

**怎么写**：只锁一种风格词，全篇不漂移。风格词要落在画面特征上，不要只写“好看的风格”。

```text
英文：3D animated film style, soft rounded shapes, Pixar-like
中文：3D 动画电影风格，圆润柔和的造型
```

### 3. 材质（Material）

**看什么**：主要物体的表面——是哑光还是亮面，是布料、塑料、金属、陶瓷还是玻璃；表面有没有反光、纹理、绒毛、水珠。

**怎么写**：每个大面积物体配一个材质词；材质词是“高级感”最便宜的来源，但图里看不清的材质不要猜。

```text
英文：matte plastic texture, fluffy fabric, glossy ceramic
中文：哑光塑料质感、毛绒面料、亮面陶瓷
```

### 4. 光线（Light）

**看什么**：光从哪里来（窗户、灯、太阳）；从哪个方向打过来（左、右、头顶、背后）；光是硬还是软；阴影长什么样（长影、柔和的影、轮廓光）；画面是白天、傍晚还是夜里。

**怎么写**：光源 + 方向 + 质感三件套，不要只写“好看的光”。主光和辅光分清主次，不要写两个打架的光源。

```text
英文：warm afternoon light from the left window, soft shadows,
a thin rim light on the character's outline
中文：午后暖光从左侧窗户照进来，阴影柔和，角色轮廓有一圈薄薄的轮廓光
```

### 5. 构图（Composition）

**看什么**：主体在画面什么位置（居中、偏左、三分法交点）；留白在哪里、有多少；前景有什么、背景有什么；画面有没有被裁切的感觉。

**怎么写**：位置、留白、前后景三样写清。留白要写清位置和用途（上方留白以后放标题），不要只写“有留白”。

```text
英文：centered composition, generous negative space above the subject,
a blurred plant in the foreground
中文：居中构图，主体上方大面积留白，前景有一株虚化的植物
```

### 6. 镜头（Camera）

**看什么**：拍的是特写、中景还是全景；镜头是平视、仰拍还是俯拍；画面有没有景深（背景虚不虚）；有没有广角拉伸或长焦压缩的感觉。

**怎么写**：景别 + 焦段 + 角度。景别、焦段、角度要互相配得上：远景配广角、特写配长焦，别写出镜头装不下的画面。看不准焦段时只写景别和角度，不猜数字。

```text
英文：medium shot, 50mm lens, eye level, shallow depth of field
中文：中景，50mm 镜头，平视，浅景深
```

### 7. 色彩（Color）

**看什么**：画面主色是哪两三个颜色；配色是暖还是冷；饱和度高还是低；有没有一个跳出来的点缀色；背景色和主体色是什么关系。

**怎么写**：落到具体颜色名上，不要只写“色彩丰富”。主色、点缀色、背景色分开写，顺序是主色先、点缀色后。

```text
英文：pink and cream palette with a pop of green, warm tones, high saturation
中文：粉白配色加一抹绿色，暖色调，高饱和
```

### 8. 氛围（Mood）

**看什么**：画面给人的感觉——安静、热闹、孤独、温馨、紧张；这种感觉是靠什么东西撑起来的（空荡的街道、暖光、一个人影）。

**怎么写**：情绪词必须落到可见的东西上。只写情绪词等于没写，要把情绪翻译成画面元素。

```text
英文：cozy lazy Sunday afternoon mood: warm light, a half-finished drink,
the room quiet except for the treadmill hum
中文：慵懒的周日午后氛围：暖光、喝了一半的饮料、房间里只有跑步机的轻响
```

### 9. 画质词（Quality）

**看什么**：画面清不清楚、有没有噪点、细节多不多、边缘锐不锐利。

**怎么写**：留一两个就够（`highly detailed, sharp focus`），不要堆叠。画质词是锦上添花，不是主体；堆满了反而挤占有效长度，还容易出塑料感。

```text
英文：highly detailed, sharp focus
中文：细节清晰，焦点锐利
```

## 二、画面内文字：怎么处理

图里有文字时，单独处理，不要混进主体描述：

1. **原样转录**：招牌、海报、标签、字幕上的字，一个字不改地抄下来；认不清的字写“图中看不清”，不要猜。
2. **只用一种语言**：中文画面全中文，英文画面全英文。图里本身就是中英混排的，如实写进分析里并提醒用户（复现时要按铁律 5 统一成一种语言）。
3. **位置写清**：文字在画面哪里（左上角的招牌、杯身上的标签），写进构图那一维，不要只写文字内容。
4. **转录和提示词分开**：转录的文字放进“原图要点分析”里；要不要把文字写进提示词正文，看用户想不想复现它——想复现就写进正文，不想就只留在分析里。

```text
英文：a small paper tag on the cup reads "GOOD DAY" in English
中文：杯身上贴着一张小纸标签，上面写着英文“GOOD DAY”
```

## 三、常用表述模板

反推出的提示词按这个顺序拼，九维不必全写满，没内容的空着：

```text
英文版：
<主体：数量 + 外貌 + 服装 + 姿态 + 道具>, <风格>,
<材质>, <光线：光源 + 方向 + 质感>,
<构图：位置 + 留白 + 前后景>, <镜头：景别 + 焦段 + 角度>,
<色彩：主色 + 点缀色>, <氛围：情绪落到可见的东西上>,
<画质词：一两个>

中文版：
<主体：数量 + 外貌 + 服装 + 姿态 + 道具>，<风格>，
<材质>，<光线：光源 + 方向 + 质感>，
<构图：位置 + 留白 + 前后景>，<镜头：景别 + 焦段 + 角度>，
<色彩：主色 + 点缀色>，<氛围：情绪落到可见的东西上>，
<画质词：一两个>
```

常用句式（中英对照）：

| 用途 | 英文句式 | 中文句式 |
|---|---|---|
| 主体开场 | `a/an <主体>, <外貌>, <姿态>` | `一个<主体>，<外貌>，<姿态>` |
| 光线 | `<光源> from the <方向>, <质感>` | `<光源>从<方向>照进来，<质感>` |
| 构图留白 | `generous negative space <位置>` | `<位置>大面积留白` |
| 镜头 | `<景别>, <焦段> lens, <角度>` | `<景别>，<焦段>镜头，<角度>` |
| 色彩 | `<主色> palette with a pop of <点缀色>` | `<主色>配色加一抹<点缀色>` |
| 氛围 | `<情绪> mood: <可见元素>` | `<情绪>氛围：<可见元素>` |

## 四、常见坑

### 1. 别把推测当事实

图里看不见的东西，不要写进提示词。错法：看到一张海边照片就写 `a beach in Hawaii`——地点是猜的，模型会按夏威夷的样子画，复现就跑偏了。改法：只写看得见的——`a sandy beach, palm trees, turquoise sea`；地点不确定就写“图中看不出地点”，放进说明里标明是推测。

### 2. 别给图里没有的东西加戏

反推不是续写。错法：图里只有一只猫，就写 `the cat chases a butterfly`——蝴蝶是编的，复现出来的图多了个不存在的东西。改法：图里有什么写什么，没有的不要补；用户想加东西，让他明说，那是生成工作流的事，不是反推的事。

### 3. 别把风格词写成空话

`beautiful style`、`nice art`、`amazing quality` 这类词，模型无法执行。错法：看到一张水彩画只写 `watercolor style, beautiful`。改法：风格落到画面特征上——`watercolor painting, soft edges, paper texture, colors bleeding into each other`；图里看得见的特征有多少写多少，写不出的不硬凑。

### 4. 画面文字别翻错

图里的文字不要翻译、不要改写、不要“顺手润色”。错法：海报上写着“好好吃饭”，反推写成 `a poster that says "Eat Well"`——意思对了，字不对，复现出来就不是原图。改法：原样转录“好好吃饭”，提示词里写 `a poster on the wall with the Chinese text "好好吃饭"`；画面内文字只用一种语言，见铁律 5。

### 5. 别把比例写进提示词正文

画幅比例（16:9、9:16、1:1）是生成设置，不是画面内容。错法：提示词里写 `16:9 aspect ratio`。改法：比例写在“原图要点分析”里，提交时在生成设置里选；Midjourney 用 `--ar` 参数，见 `references/model-guides.md`。

### 6. 别把情绪词当画面

`lonely`、`hopeful`、`epic` 这类词要落到可见的东西上，否则模型只能瞎猜。错法：氛围只写 `lonely mood`。改法：写撑起这种感觉的东西——`an empty street at dusk, one figure walking away, long shadows`。

### 7. 别把参考图和反推对象搞混

反推的对象是用户贴的那张图本身；参考图是另外一回事。用户说“按这张图的风格，再画一个别的”，那是生成工作流 A（拿这张图当风格参考），不是反推。反推只回答一个问题：这张图本身是怎么画出来的。

## 五、视频怎么反推

视频反推用首帧（或关键帧）当反推对象：

1. **先定帧**：用户给视频，就让他指一帧（开头、中间最有代表性的一帧、结尾），或直接拿首帧；一帧反推不出的运动，换一帧再看。
2. **先反推静帧**：按上面九维把这一帧写成图片提示词，画面内容、光线、构图、色彩一次定死。
3. **再补视频七维**：主体运动、镜头运动、时间节奏、转场、音频、一致性——能从视频里看出来的才写（比如镜头在推近、音乐是轻柔钢琴）；只看一帧猜不出的运动，写“单帧看不出，需看原视频确认”，不要编。
4. **首帧锁定**：反推出的提示词要拿去跑图生视频时，首帧锁定用固定句式，一字不改：`@Image N is the first frame.`；尾帧同理：`@Image N is the last frame.`；首尾帧比例必须一致。

## 六、交付前自检表

交之前逐项打勾：

- [ ] 九维都看过一遍，没内容的维度空着，没硬凑。
- [ ] 提示词里的每个词，图里都找得到对应物。
- [ ] 推测的内容标明了“推测”，没混进提示词正文。
- [ ] 画面内文字原样转录，且只用一种语言。
- [ ] 画幅比例写在说明里，没写进提示词正文。
- [ ] 风格词只锁一种，全篇没漂移。
- [ ] 还原度要点列了 3–5 个，按重要性排过序。
- [ ] 可调参数写清了“改哪里调哪里”，用户不用自己翻提示词。
- [ ] 否定提示词只放画面通病类词，没放剧情否定。
- [ ] 中英两个版本意思一致，英文版没残留中文词，中文版没残留英文词（模型参数和锁定句式除外）。
