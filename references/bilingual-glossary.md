# 中英对照核心词表（bilingual-glossary）

写提示词时先想中文意思，再从这里挑对应的英文说法。不要逐字直译：先把意思落到看得见的东西上，再翻译。

用法：左列中文是“意思”，右列英文是“提交给模型时用的说法”。带 ※ 的是容易直译翻车的地方，见每组下面的提示。

---

## 一、画面与主体（Subject）

| 中文意思 | 英文说法 |
|---|---|
| 一个人 / 两个人 | one person / two people |
| 年轻女人 / 中年男人 | a young woman / a middle-aged man |
| 小孩 / 老人 | a child / an elderly person |
| 黄色圆润角色 | a yellow round chubby character |
| 大眼睛 / 小短腿 | big blue eyes / tiny short legs |
| 长发 / 短发 / 卷发 | long hair / short hair / curly hair |
| 穿白色连衣裙 | wearing a white cotton dress |
| 穿洗旧的工装 | wearing a worn-out blue work jacket |
| 坐着 / 蹲着 / 躺着 | sitting / crouching / lying down |
| 回头看 / 低头 / 抬头 | looking back over the shoulder / looking down / looking up |
| 手里拿着杯子 | holding a cup in one hand |
| 一只橘猫 | an orange tabby cat |
| 一条小鱼 | a small fish |
| 空无一人的街道 | an empty street, no one in sight |
| 背景里有植物和海报 | a plant and a poster on the wall in the background |

※ 数量要写死：中文说“几个”很含糊，英文必须写 `one / two / three` 这样的确数；“一些”不要写 `some`，直接写数字。

## 五、色彩（Color）

| 中文意思 | 英文说法 |
|---|---|
| 粉白配色 | pink and cream palette |
| 米白 | cream / off-white（不要写 rice white） |
| 暖色调 | warm tones |
| 冷色调 | cool tones |
| 高饱和 | high saturation |
| 柔和粉彩 | soft pastel |
| 黑白 | black and white / monochrome |
| 青橙色调 | teal and orange grade |
| 一抹绿 | a pop of green |
| 品牌主色 | brand color, locked to <颜色名或色值> |

※ “米白”直译成 `rice white` 模型读不懂，用 `cream` 或 `off-white`；“高级灰”不要写 `high-level gray`，写 `muted gray tones, low saturation`。

## 六、动作（Action Verbs）

动作词越具体越好，不要用“做”“弄”“搞”这类空动词。

| 中文意思 | 英文说法 |
|---|---|
| 蹲下 | crouch / crouch down |
| 跳 / 跃起 | leap / jump |
| 猛推 / 拽 | shove / yank |
| 旋转 / 疾跑 | spin / dash |
| 拖 / 弹 | drag / flick |
| 猛击 / 抓 | pound / grab |
| 扭 / 扔 | twist / hurl |
| 推开门 | push the door open |
| 叼起 | pick up in its mouth / snatch |
| 压低身子 | lower its body close to the ground |
| 慢慢靠近 | approach slowly |
| 回头看一眼 | glance back |
| 停一拍 | pause for a beat |
| 呼吸 / 喘气 | breathe / pant |
| 挥手 / 招手 | wave |
| 坐下 / 站起 | sit down / stand up |

※ 中文“他努力跑”不要写成 `he runs with all his might`（模型读到的还是普通跑步），要写画面：`signs flash past, dust kicks up at his heels`。

## 七、情感与氛围（Mood）

情绪词必须落到可见的东西上，不要只写一个形容词。

| 中文意思 | 英文说法（落到画面上） |
|---|---|
| 孤独 | an empty street at dusk, one figure walking away, long shadows |
| 温馨 | warm lamplight, a blanket, a half-finished cup of tea |
| 慵懒的周日午后 | lazy Sunday afternoon: warm light, a half-finished drink, quiet room |
| 紧张 | a hand gripping the door handle, shallow fast breathing |
| 史诗感 | a thousand-strong crowd, endless mountains, wide aerial shot |
| 安静 | a quiet room, no one speaking, only the clock ticking |
| 治愈 | soothing, calm, warm light, slow pace（不要写 healing） |
| 氛围感 | 不要直译 atmosphere feeling；写具体：low warm light, thin haze, quiet street |
| 高级感 | 不要直译 high-level feeling；写具体：muted tones, matte texture, generous negative space, restrained composition |

※ “氛围感”“高级感”“治愈”这类中文抽象词没有对应的英文单词，硬译就是翻译腔。正确做法是把它们拆成光线、材质、留白、节奏这些可见的东西。

## 十、文案与营销（Copy & Marketing）

| 中文意思 | 英文说法 |
|---|---|
| 广告语 / 口号 | tagline / slogan |
| 产品卖点 | selling point / key benefit |
| 目标用户 | target audience |
| 痛点 | pain point |
| 行动号召 | call to action (CTA) |
| 限时优惠 | limited-time offer |
| 免费试用 | free trial |

## 十二、常用句式（Sentence Patterns）

| 用途 | 英文句式 | 中文对照 |
|---|---|---|
| 定主体 | `a <特征> <主体>, <姿态>, <在做什么>` | 一个……的……，正在…… |
| 定风格 | `<风格词>, <风格补充>` | ……风格，…… |
| 定光线 | `<光源> from <方向>, <质感>` | ……光从……来，…… |
| 定镜头 | `<景别>, <焦段>, <角度>` | ……景别，……镜头，……角度 |
| 定一致性 | `Keep <A>, <B>, and <C> consistent throughout.` | 全程保持……不变 |
| 定首帧 | `@Image 1 is the first frame.` | 图 1 是首帧 |
| 定尾帧 | `@Image 2 is the last frame.` | 图 2 是尾帧 |
| 定否定（负向栏） | `--no <词>, <词>` | 不要：…… |
| 定音频 | `(音乐) <音效> {对白}` | 音乐……、音效……、对白…… |

## 翻译避坑速查

| 中文原意 | 错误直译 | 正确做法 |
|---|---|---|
| 氛围感 | atmosphere feeling | 写可见元素：low warm light, thin haze |
| 高级感 | high-level feeling | 写材质 + 留白 + 克制配色 |
| 治愈 | healing | soothing / calm / warm |
| 米白 | rice white | cream / off-white |
| 种草 | plant grass | honest recommendation |
| 爆款 | explosive product | bestseller / viral hit |
| 绝绝子 | absolutely amazing | 删掉，换成具体描述 |
| 他努力跑 | he runs with all his might | 写画面：signs flash past, dust at his heels |
| 光线很美 | beautiful light | 光源 + 方向 + 质感 |
| 很漂亮的女孩 | a very beautiful girl | 写具体长相：年龄、头发、衣服、姿态 |
